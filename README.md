# Maji Ndogo Water Infrastructure Dashboard

## Project Overview

This project is an interactive Power BI dashboard built to analyse water access, infrastructure improvements, population impact, and budget requirements across Maji Ndogo.

The dashboard provides a national-level overview and detailed reports for five provinces:

- Akatsi
- Amanzi
- Hawassa
- Kilmani
- Sokoto

The goal was to transform water-service data into clear insights that can help decision-makers understand where improvements are needed, what infrastructure is required, and how much the improvements may cost.

## Key Findings

The analysis revealed several important findings:

- Basic water access currently stands at approximately **34%** of the population.
- The estimated infrastructure upgrade budget is approximately **$147M**.
- Planned infrastructure improvements have the potential to significantly increase access to basic water.
- Infrastructure needs and budget requirements vary considerably across provinces and towns.
- Rural infrastructure requires additional cost consideration compared with urban areas.
- Different improvement types contribute differently to the overall infrastructure budget.
- Town-level analysis helps identify areas that require greater investment relative to their population.
- Cost-per-citizen analysis provides another way to compare the financial requirements across locations.

## Business Problem

Maji Ndogo needs to understand the current state of water access and determine where infrastructure improvements should be prioritised.

The dashboard helps answer questions such as:

- What percentage of the population currently has access to basic water?
- How many people are affected by different water sources?
- How many improvements are required?
- Which improvement types are most common?
- How much will the improvements cost?
- How is the budget distributed across provinces?
- How does spending differ between rural and urban areas?
- What is the cost per citizen?
- Which towns require the most investment?

## Project Objectives

The main objectives of this project were to:

1. Analyse water access at the national level.
2. Compare population and infrastructure needs across provinces.
3. Analyse the number and types of required improvements.
4. Calculate infrastructure improvement costs.
5. Analyse budget allocation by province, town, and improvement type.
6. Compare rural and urban spending.
7. Calculate cost per citizen.
8. Create detailed provincial reports for deeper analysis.
9. Build an interactive Power BI report using navigation and drill-through functionality.

## Dashboard Structure

### National Level

The national dashboard provides a high-level overview of the water situation across Maji Ndogo.

It includes:

- Percentage of population with access to basic water
- Total infrastructure budget
- Percentage improvement
- People affected by different water-source types
- Number of planned improvements
- Improvement breakdown
- Provincial population and budget
- Budget allocation by province
- Provincial comparison
- Interactive province selection

### Provincial Reports

The report contains detailed pages for five provinces.

#### Akatsi

Provides analysis of town population, improvement requirements, budget, cost per citizen, budget allocation, rural/urban spending, and improvement types.

#### Amanzi

Provides detailed analysis of population, infrastructure improvements, budget allocation, rural/urban spending, and town-level costs.

#### Hawassa

Shows population, improvement requirements, budget allocation, rural/urban spending, improvement types, and infrastructure costs.

#### Kilmani

Provides detailed analysis of town-level requirements, improvement quantities, budget distribution, and rural/urban spending.

#### Sokoto

Shows town-level population, improvement requirements, budget, cost per citizen, rural/urban spending, and improvement priorities.

## Key Dashboard Features

### Interactive Province Selection

Users can select a province from the national dashboard to explore the available information.

### Drill-through Analysis

The report allows users to move from the national overview into detailed provincial reports for deeper analysis.

### Rural vs Urban Analysis

Infrastructure spending is analysed across rural and urban locations to understand differences in investment requirements.

### Budget Analysis

The dashboard analyses budget requirements by:

- Province
- Town
- Improvement type
- Rural/urban location

### Improvement Analysis

The dashboard provides a breakdown of required improvements, including:

- Drill well
- Install RO filter
- Install UV and RO filter
- Install public tap(s)
- Repair infrastructure

### Cost per Citizen

Cost-per-citizen metrics help compare the financial requirements of different towns and provinces relative to their population.
